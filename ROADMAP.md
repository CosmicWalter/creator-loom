# Roadmap

This is a delivery backlog, not a promise that the complete product is already available. Each implementation change should include appropriate verification and a reviewable Git commit under `CosmicWalter`.

## Foundation — in progress

- [x] Independent, MIT-licensed codebase without private project material.
- [x] CLI, seven explicit recipes, model capability cards and inspectable routing.
- [x] Model/technique/preference snapshots, local state, submit-once behavior and artifact-bound review.
- [x] Profile-specific feedback, public feed reading, sourced technique proposals, paired review, activation and rollback.
- [x] Loopback provider contract tests and real FFmpeg pipeline tests with simulated inference.
- [x] Global workflow model allocation instead of greedy step selection.
- [x] Stronger evaluation controls: frozen model/preference contexts and active baseline checks.
- [x] Review rubrics, changed revision artifacts and self-reported creator practice progress.
- [ ] Holdout sets, blind reviews and independently measured creator skill gains.

## Real creative delivery

- [ ] Authorize and validate real text/image/speech providers using synthetic licensed briefs.
- [x] Record adapter wall time, outcomes and provider-reported chat token usage; expose configured-rate cost estimates and missing coverage.
- [x] Task-specific quality priors, feedback isolation by backend signature, observed reliability and conservative latency.
- [x] Reserve upstream output bounds against downstream input capacity in joint allocation.
- [ ] Calibrate model priors and quality dimensions using reviewed real-provider creative tasks and actual billing evidence.
- [x] Authorized reference-voice selection and local CLI timeline with reviewed cuts, still-image zoom, explicit subtitle timing and narration/music mixing.
- [ ] Automatic speech alignment, ducking/loudness controls, transitions and generative video delivery.
- [x] MediaFlow narration adapter with frozen segment requests, persistent remote IDs, safe polling/download recovery and explicit reconciliation.
- [ ] ComfyUI adapter, MediaFlow transcription delivery and additional asynchronous model providers.
- [x] Bounded TXT/unencrypted EPUB import, chapter/unit provenance and reviewed sequential creation with frozen continuity notes.
- [x] Versioned CLI edit lists, per-shot review, sealed rendering and final approval over hash-bound sources.
- [ ] Rich character memory, automatic continuity proposals and a workbench timeline editor.
- [x] Authenticated loopback workbench, frozen plan confirmation, artifact preview/review and structured deliverable export.
- [x] Workbench book import, sequential creation, research inbox and text revision practice backed by existing APIs.
- [ ] Browser interaction/visual acceptance and further usability iteration; generalized media asset library and timeline editing.

## Learning system and open benchmark

- [x] Saved public source subscriptions, literal keyword triage, deduplicated/versioned evidence and reviewed proposal inbox.
- [x] Foreground due-source collector with leases, persistent intervals and isolated source failures.
- [ ] Semantic technique synthesis, license/compatibility review and automated experiment proposals beyond editorial guidance.
- [ ] Sandboxed adapter/recipe proposals; regression suites, signed releases and reversible migrations.
- [x] CLI task-isolated A/B review protocol, preassigned holdout briefs and explicit holdout-only quality calibration (synthetic protocol verification).
- [ ] Independently conducted real-provider blind reviews and budget-matched comparisons.
- [ ] Outcome-based model calibration, fallback decisions and auditable cost accounting.
- [ ] Evidence of creator skill improvement through exercises and independently scored revisions.
- [ ] Publish reproducible evaluations; no claim of an industry benchmark before comparative evidence exists.
