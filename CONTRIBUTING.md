# Contributing

Use Python 3.11+ and run the commands in the README. Contributions should solve a concrete creator problem and include appropriate tests. Keep the core dependency-free unless a dependency enables a reviewed capability that cannot be implemented reasonably otherwise.

Adapters must document their real API contract, supported inputs, authorization, billing units and uncertainty/recovery semantics. Never simulate model output in production or convert a failure into a success. Test fixtures and simulated providers must be explicitly identified.

Use synthetic or properly licensed content. Do not include personal metadata, credentials, production logs, private prompts, runtime databases or model weights. Reports of quality improvement need reproducible methods and evidence, not only green unit tests.

Code you contribute must be yours to contribute under this repository's MIT license. Third-party code keeps its original license and attribution, and must be compatible with distribution here.
