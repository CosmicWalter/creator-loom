# Changelog

## 0.14.0

- Add bounded, versioned character memory for reviewed series: identity, appearance, relationships, state and editorial constraints, each with an exact source/accepted-episode citation and human review.
- Freeze character facts into future episode plans, count them against model input capacity, preserve historical memory versions and block edits while an episode is pending.
- Verify memory/source hashes before planning, execution, approval and comparison; reject future-unit, unaccepted and cross-series episode references. Prompts contain creative facts, excluding memory record IDs and reviewer notes.
- Add workbench fact/citation editing, available-evidence reading and explicit historical restoration as a new reviewed version, with matching CLI and legacy empty-memory migration.
- Cover original synthetic fiction, simulated inference and real authenticated HTTP flows. Quote checks do not verify semantic truth or resolve contradictions; automatic continuity suggestions and real-model consistency evidence remain pending.

## 0.13.0

- Add immutable, hash-bound A/B comparisons for saved UTF-8 text practice revisions, with randomized presentation and neutral-timestamp review packets that exclude previous self-scores, editing rationale and version mappings.
- Preserve direct shared text inputs, authorized source context and public credits for meaningful review. Verify source/revision integrity before packet export, scoring, report and aggregation.
- Separate self reviews from externally declared reviews in growth summaries; invalidate changed/missing artifact comparisons rather than silently counting them. External reviewer identity/independence is not verified.
- Connect the flow to the workbench growth view and CLI with authenticated previews and immutable scoring. No practice scores enter model routing feedback.
- Add synthetic revision/reviewer and real HTTP tests. Revision-quality deltas are not causal evidence of durable creator skill gains, and browser acceptance remains pending.

- Freeze same-model, shared-upstream paired experiments with randomized A/B presentation, sealed development and reserved holdout review. Only recorded holdout scores can reach technique evaluation; model routing feedback is not calibrated by technique experiments.
- Add workbench and CLI synthesis/experiment flows through explicit activation and rollback. Preserve inherited methods for other tasks using flat effective-method maps and hashed baseline references, with legacy snapshot reads.
